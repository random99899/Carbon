# 问题一脚本说明

## 脚本

- `solve_problem1.py`

## 使用算法与模型

- 变异系数、基尼系数、泰尔指数：度量省际碳排放总量、人均排放、排放强度、煤炭占比差异。
- 熵权TOPSIS：构建低碳发展综合评价得分与等级。
- K-means聚类：将30省划分为资源依赖高排放型、工业制造高排放型、中等转型压力型、经济发达效率型。

## 输入

- `数据/2022省级综合表.xlsx`
- 使用工作表：`主表`
