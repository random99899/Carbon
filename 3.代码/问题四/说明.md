# 问题四脚本说明

## 脚本

- `solve_problem4.py`

## 使用算法与模型

- 问题四不单独建立新数学模型，而是综合问题一的省份分类、问题二的驱动因素识别、问题三的情景预测结果。
- 按“区域类型-关键驱动-达峰预测-政策路径”的逻辑生成政策建议报告。

## 输入

- 问题一、问题二、问题三脚本计算结果。
- 脚本单独运行时会自动重新调用前三问计算函数。

## 输出

- `1.结果/问题四/问题四_政策建议报告.md`

## 运行

```powershell
.\.venv\Scripts\python.exe .\3.代码\问题四\solve_problem4.py
```
