# 问题三脚本说明

## 脚本

- `solve_problem3.py`

## 使用算法与模型

- 全国排放时间序列统计：只使用附件1中`Sector=Total`的全国总量。
- Kaya-STIRPAT情景递推：设置人口、人均GDP、能源强度、能源碳强度变化率，预测2026-2045年排放。
- 达峰研判：逐情景寻找峰值年份、峰值水平和2045年减排潜力。

## 输入

- `数据/附件1：2019—2025 年全国碳排放数据.csv`
