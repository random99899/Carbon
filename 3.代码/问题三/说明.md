# 问题三脚本说明

## 脚本

- `solve_problem3.py`

## 使用算法与模型

- 全国排放时间序列统计：只使用附件1中`Sector=Total`的全国总量。
- STIRPAT系数递推：使用问题二OLS估计系数，构建`ΔlnC = β1ΔlnP + β2ΔlnA + β3ΔCoal + β4ΔIS + β5ΔU`。
- 三情景驱动变量路径：设置人口、人均GDP、煤炭占比、第二产业占比、城镇化率的年度变化，预测2026-2045年排放总量和碳排放强度。
- 达峰研判：逐情景寻找峰值年份、峰值水平、2045年减排潜力和碳排放强度下降比例。

## 输入

- `数据/附件1：2019—2025 年全国碳排放数据.csv`
- `数据/全国数据.xlsx`
- 问题二STIRPAT回归系数

- `1.结果/问题三/03_情景参数.csv`

- `2.图片/问题三/08_三情景峰值与减排潜力对比图.png`
