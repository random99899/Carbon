# 问题二脚本说明

## 脚本

- `solve_problem2.py`

## 使用算法与模型

- STIRPAT横截面模型：识别人口规模、人均GDP、煤炭占比、第二产业占比、城镇化率对碳排放的影响。
- OLS回归：估计模型参数并输出显著性检验。
- VIF检验：判断解释变量共线性。
- 岭回归留一交叉验证：检验驱动因素排序和模型预测稳定性。

## 输入

- `数据/2022省级综合表.xlsx`
- 使用工作表：`主表`

## 输出

- `1.结果/问题二/01_OLS系数.csv`
- `1.结果/问题二/02_拟合优度.csv`
- `1.结果/问题二/03_VIF共线性检验.csv`
- `1.结果/问题二/04_拟合值残差.csv`
- `1.结果/问题二/05_岭回归交叉验证.csv`
- `1.结果/问题二/06_岭回归标准化系数.csv`
